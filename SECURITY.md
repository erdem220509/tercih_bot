# Security Policy

## Reporting a vulnerability

Please do not disclose a vulnerability, exploit steps, personal data, or credentials in a public issue.

Use GitHub's **Security → Report a vulnerability** option for this repository. If private vulnerability reporting is not available, open a public issue containing only a short request for a private contact channel—do not include technical details.

Include the affected route or component, the impact, reproduction steps, and a suggested mitigation when possible. Reports made in good faith will be reviewed as soon as practical.

## Supported version

Only the code currently deployed at [unipusulam.com](https://unipusulam.com) is supported with security fixes.
